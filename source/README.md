# Zunéviu for Android

Music, made personal. Lightweight settings, clean lyrics and a focused listening experience.

## Development

This is the development source for Zunéviu 1.2.5 build 47 (restore live video lyrics). See BUILDING.md for builds and owner release operations. Official APK downloads: https://github.com/amitsami/zunevio-releases/releases/latest.

- Optimized Android production build, Android 8.0 and later.
- In-app stable updates with changelogs, verified downloads and Android-confirmed installation.
- A single release workflow stages the same APK/source/checksum assets on both release channels.
