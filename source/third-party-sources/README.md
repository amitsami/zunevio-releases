# Preserved dependency sources

Exact tagged sources are included for NewPipeExtractor v0.26.3, InnerTubeX v0.7.0 and Rhino 1.8.1. Their upstream licenses are inside each archive. MIT-licensed Beat This! and Open-Unmix source snapshots are also preserved for model attribution. SHA256.json identifies these archives. App-specific compatibility replacements and native decoder modifications are in the main source tree, not edits hidden in these ZIPs. Build files specify the dependency versions; these copies do not include owner credentials.
